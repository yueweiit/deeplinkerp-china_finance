# 现金流量指定单列表处理

从“中国财务”选择公司后，打开“现金流量指定单”，即可在列表中处理。指定单仍关联原中国会计凭证和来源单据，原表单保留作废、修订和审计入口。

## 日常处理

1. 在“待处理”中按记账月份、日期、凭证或来源单据检索。方向筛选命中某笔现金明细时，仍展示该整张指定单的所有现金明细。
2. 在现金明细中选择项目。项目按本公司的有效模板和收付方向显示；系统建议只供核对，已有人工指定不会被“填入系统建议”覆盖。
3. 一笔现金属于多个项目时点击“拆分”，逐项填写项目、正数金额及依据。指定金额合计须等于该笔现金发生额；现金发生额不会因拆分重复累计。
4. 点击“保存更改”保存草稿。项目和金额需满足原表单必填要求；金额尚未配平可以保存草稿，但不能确认。
5. 勾选整张指定单，点击“确认所选”，核对可处理单据和具体缺项后确认。确认成功后纳入现金流量统计、明细只读。失败单据保留编辑内容并显示逐单原因。

## 权限与共同操作

- 财务经办按现有权限保存指定；确认沿用原有主管/经理权限。公司启用职责分离时，指定人与确认人必须不同。
- 多人同时修改时会检查版本。提示版本已变化后，先核对服务器记录再决定是否重新指定；旧版本不会覆盖他人新保存的内容。
- 切公司、筛选、分页或离开时如有未保存内容，会提示是否放弃。自动刷新遇到未保存内容会暂停。
- 已确认、已作废单据只读。需要更正时，从“详情”打开原始指定单，沿用作废原因与修订流程。

本功能只改变现金流量项目的指定与确认，不重记来源凭证，也不新增收付款、库存或总账事实。

## 查询与分页约定

`services/cash_flow_assignment_list.py:get_assignment_list` 复用 Frappe 列表权限，在数据库中按状态统计父单据并分页，每页最多 100 张，再读取当页单据的完整明细。方向、明细关键词及有读取权限的会计凭证摘要通过 SQL 子查询筛选，不将全部命中编号读入应用内存；方向与关键词允许命中同一单据的不同明细，状态计数不因多个明细匹配而重复。
